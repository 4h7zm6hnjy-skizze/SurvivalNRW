SURVIVAL DEUTSCHLAND v1.5.0
===================================
Offlinefähige PWA für GitHub Pages. Alle Dateien flach in das Stammverzeichnis hochladen; kein Unterordner erforderlich.
Neu: Offline-Übersichtskarte mit echten Bundeslandgrenzen, keine Straßen- oder topografische Wanderkarte. GPS erfordert HTTPS und Standortfreigabe.
Bundesländer direkt unten in der Navigation; Knotenschule und bekannte Module bleiben erhalten.
9 Unterschlupf-Typen und Tierkapitel Reh, Wildschwein, Hase, Federwild mit erklärenden KI-Motiven. Bilder sind keine anatomisch geprüften Fototutorials.
BfR und Tier-LMHV Hinweise zur Wildbrethygiene und Trichinenuntersuchung berücksichtigen.
Geografische Grenzdaten: isellsoap/deutschlandGeoJSON, GIS-DATA, Unlicense, vereinfacht.
Bitte einen eigenen GPS- und Flugmodus-Test auf dem iPhone durchführen; der Browser kann Cache löschen.
